# Summary  
__Level:__ Warning  

__Purpose:__ This rule intends to push authors towards using em dashes instead of double dashes (--). An em dash is visually cleaner, and more appropriate in most written communications.

__Invalid Examples:__  
  - "--"
 
__Valid Examples:__  
  - "&mdash;"
