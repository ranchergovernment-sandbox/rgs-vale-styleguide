# Summary  
__Source:__ [Spacing](../../RGS/styles/RGS/Spacing.yml)

__Level:__ Error  

__Purpose:__ This rule ensures that there is one, and only one, space after a sentence ending punctuation mark.

__Invalid Examples:__  
  - "Harvester Government.  Is a hypervisor"
  - "RGS Security.Is a security tool"
 
__Valid Examples:__  
  - "Harvester Government. Is a hypervisor"
  - "RGS Security. Is a security tool"
