# Summary  
__Source:__ [Editorializing](../../RGS/styles/RGS/Editorializing.yml)

__Level:__ Warning  

__Purpose:__ This rule attempts to steer authors away from the use of terms, and phrases that are not appropriate for technical documentation. These words and phrases often do not add substance to technical documentation, and can be perceived as filler, or fluff.  

Some content may find it useful to disable this rule as it is directed towards technical documentation specifically. For example, a corporate blog post should disable this rule. 

__Invalid Examples:__  
  - fortunately
  - huge
  - in fact
  - in general
  - interestingly
  - is a number
  - it is important to realize
 
__Valid Examples:__  
  - N/A
