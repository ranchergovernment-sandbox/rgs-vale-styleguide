# Summary  
__Source:__ [Contractions](../../RGS/styles/RGS/Contractions.yml)

__Level:__ Suggestion   

__Purpose:__ This rule attempts to steer authors away from using contractions. Contractions are more casual, and natural for many readers, so there is a time and place. Contractions are also considered informal, and should typically be avoided. It is only a suggestion so it can be ignored.

__Invalid Examples:__  
  - "can't"  
 
__Valid Examples:__  
  - "cannot"
